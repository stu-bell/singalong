When using a conventional projector that isn't perfectly perpendicular to the screen, the image will be skewed/improperly sized. 

While projectors often have capability to map the corners of the projection onto the corners of the screen, that's hardware specific, and I want to be able to include that functionality in the screen setup journey of this app, since it'll commonly be projected.
resize screen - all four corners of the resize area should be draggable, so that as well as resizing, we can use with a projector, we can project at a non-perpendicular angle if necessary.

The projection mapping must have minimal performance impact on the video display or memory. Consider any performance considerations of this and use browser based optimisations where possible.
